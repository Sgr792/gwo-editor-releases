# GWO 内容编辑器

GWO 内容包的 Windows 桌面工作台。此仓库仅提供程序下载和签名更新清单，不包含模组源码或枪械内容包。

[下载最新版本](https://github.com/Sgr792/gwo-editor-releases/releases/latest)

## 0.1.4 预览版

- 中文界面，打开本地内容包目录，浏览和搜索配置与资源。
- 属性表单及 JSON 编辑，保留未知字段；保存前留存历史副本，检测外部文件修改。
- 第一人称 / 自由视角切换，按枪械相机节点和 FOV 预览，随动画更新并支持临时调整 FOV。
- 第一人称显示玩家手臂，可选 Steve 宽手臂、Alex 细手臂或隐藏；手臂随枪械动画移动。
- 枪械默认配件装配，支持外部定义、渲染引用、枪械覆盖和父子安装点。
- GLB 模型、颜色贴图与动画源预览，动画选择、播放、暂停、拖动时间及骨架检查。
- PNG 预览，OGG/WAV 播放，导入资源。
- 检查 JSON 语法、当前包资源引用和基础数值，导出 ZIP 开发内容包。
- 启动时检查更新，也可在“设置 / 更新”中手动检查。用户点击下载安装，更新清单使用 Ed25519 签名，安装文件使用 SHA-256 校验。

## 使用

可选择安装版，或下载 `GWO-Editor-0.1.4-Portable.zip` 免安装版。免安装版需完整解压后双击 `GWO 内容编辑器.exe`，请保留同目录的 DLL、resources 和 locales。0.1.1 起免安装版支持在线升级：在“设置 / 更新”中检查并下载，点击“更新并重启”。程序会校验 ZIP 和文件清单，退出后替换程序文件并重新启动；出现写入错误时尝试恢复旧文件。内容包和个人文件不在替换范围。0.1.0 的免安装版需手动解压升级一次。

启动编辑器后，点击“打开内容包”，选择含 `pack.mcmeta` 的目录。选择配置可编辑参数，选择 GLB 可查看模型。修改后点击“保存配置”或按 Ctrl+S。

发布给玩家前，请先在 GWO 客户端测试。当前版本是开发预览版：枪械配置预览包含默认配件，单独 GLB 预览只显示该资源；尚不复现任意改装组合、PBR 光影和完整动画状态机；基础配置模板需要补充游戏所需字段。尚不包含可视化动画事件时间轴、挂点拖拽或受保护内容包发布功能。

保存历史位于 `%APPDATA%/gwo-content-editor/backups`。更新只替换编辑器程序，不替换用户内容包。签名更新清单不等同于 Windows Authenticode 代码签名。
